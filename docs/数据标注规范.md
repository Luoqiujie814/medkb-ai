# MedKB-AI 数据标注规范

> 版本: v1.0 | 更新日期: 2025-05-29 | 适用范围: 医药文本知识抽取

---

## 1. 目的与范围

本文档定义了MedKB-AI项目中医药文本的结构化标注标准，旨在保证不同标注员（人类或AI模型）之间标注结果的一致性和可比性。

### 1.1 适用对象
- LLM标注提示词设计者
- 标注质量审核员
- 知识库维护人员

### 1.2 标注实体类型

| 实体类型 | 英文名 | 定义 | 示例 |
|---------|--------|------|------|
| 药品 (drug) | Drug | 用于预防、治疗、诊断疾病的化学物质或生物制品 | 阿司匹林、二甲双胍、胰岛素 |
| 疾病 (disease) | Disease | 机体在病因作用下出现的异常生命活动过程 | 冠心病、2型糖尿病、高血压 |
| 不良反应 (adverse_effect) | Adverse Effect | 药品在正常用法用量下出现的与用药目的无关的有害反应 | 胃肠道出血、肝毒性、皮疹 |
| 禁忌症 (contraindication) | Contraindication | 禁止使用某种药物的特定情况或人群 | 活动性溃疡、严重肾功能不全 |

## 2. 标注原则

### 2.1 通用原则

1. **标准化优先**：药品使用中国药典通用名，疾病使用ICD标准术语
2. **原文依据**：每个标注须能在原文中找到对应的文本证据
3. **最小粒度**：标注最小可独立理解的语义单元
4. **宁缺毋滥**：不确定的标注宁可省略，不可随意标注
5. **一致性**：同一实体在全文中的标注应保持一致

### 2.2 药品标注细则

#### 2.2.1 药品名称标准化
| 原文表述 | 标准标注 | 说明 |
|---------|---------|------|
| 阿司匹林 / 乙酰水杨酸 / 拜阿司匹林 | 阿司匹林 | 统一使用通用名 |
| 扑热息痛 / 泰诺 / 百服宁 | 对乙酰氨基酚 | 优先使用中国药典名称 |
| 洛赛克 | 奥美拉唑 | 商品名统一为通用名 |
| 格华止 | 二甲双胍 | |

#### 2.2.2 药品分类规范
使用WHO ATC分类体系：
- **A**: 消化道及代谢（如奥美拉唑→质子泵抑制剂，二甲双胍→口服降糖药）
- **B**: 血液及造血器官（如华法林→抗凝药）
- **C**: 心血管系统（如氨氯地平→钙通道阻滞剂）
- **J**: 全身用抗感染药（如阿莫西林→青霉素类抗生素）
- **M**: 肌肉骨骼系统（如布洛芬→非甾体抗炎药）
- **N**: 神经系统（如对乙酰氨基酚→解热镇痛药）

#### 2.2.3 药品标注示例
```json
{
  "name": "阿司匹林",
  "english_name": "Aspirin",
  "category": "抗血小板药 / 解热镇痛抗炎药",
  "mention_in_text": "阿司匹林肠溶片",
  "is_active_ingredient": true
}
```

### 2.3 疾病标注细则

#### 2.3.1 疾病vs症状的判断标准
- **疾病**：有明确的诊断标准、病理生理基础
  - ✅ 标注：冠心病、2型糖尿病、胃食管反流病
- **症状**：患者主观感受或客观体征，可能是多种疾病的表现
  - ✅ 标注：发热、头痛、恶心（标注时 category 为"症状"）
  - ❌ 不单独标注为疾病：轻微不适（过于模糊）

#### 2.3.2 疾病名称标准化
| 原文表述 | 标准标注 |
|---------|---------|
| 冠心病 / 冠状动脉粥样硬化性心脏病 / CAD | 冠心病 |
| 2型糖尿病 / II型糖尿病 / T2DM / 非胰岛素依赖型糖尿病 | 2型糖尿病 |
| 胃食管反流 / GERD / 反流性食管炎 | 胃食管反流病 |
| 脑卒中 / 中风 / 脑血管意外 / CVA | 脑卒中 |

### 2.4 不良反应标注细则

#### 2.4.1 严重程度判断标准
| 等级 | 定义 | 示例 |
|------|------|------|
| 轻度 | 不需要医疗干预，可自行缓解 | 轻度恶心、短暂的头痛 |
| 中度 | 影响日常活动，可能需要药物干预 | 持续性腹泻、中度肝功能异常 |
| 重度 | 危及生命、导致住院或永久性损害 | 消化道大出血、急性肝衰竭 |

#### 2.4.2 发生频率描述
| 频率类别 | 发生率范围 | 中文描述 |
|---------|-----------|---------|
| 十分常见 | ≥ 10% | 十分常见 |
| 常见 | 1% - 10% | 常见 |
| 少见 | 0.1% - 1% | 少见、偶见 |
| 罕见 | 0.01% - 0.1% | 罕见 |
| 十分罕见 | < 0.01% | 十分罕见、个例报告 |

### 2.5 禁忌症标注细则

#### 2.5.1 绝对禁忌 vs 相对禁忌
- **绝对禁忌**：任何情况下均不应使用
  - 示例：对本品过敏者、活动性消化道溃疡出血
- **相对禁忌**：在特定条件下谨慎使用或减量
  - 示例：肾功能不全（需根据eGFR调整剂量）

## 3. 关系标注规范

### 3.1 关系类型定义

| 关系类型 | 说明 | 方向 | 示例 |
|---------|------|------|------|
| indication | 药品治疗/适用于某种疾病 | drug → disease | 阿司匹林 → 冠心病 |
| adverse_effect | 药品可能引起某种不良反应 | drug → adverse_effect | 二甲双胍 → 胃肠道反应 |
| contraindication | 药品禁止用于某情况 | drug → contraindication | 阿司匹林 → 活动性溃疡 |
| drug_interaction | 两种药品存在相互作用 | drug → drug | 阿司匹林 ↔ 华法林 |
| first_line | 药品是某疾病的一线治疗 | drug → disease | 二甲双胍 → 2型糖尿病 |

### 3.2 证据等级标注

用于indication类型的补充标注：
- **A级**：基于多项高质量RCT（随机对照试验）或Meta分析的明确证据
- **B级**：基于单项RCT或多项非随机对照研究的证据
- **C级**：基于专家共识、病例报告或临床经验
- **D级**：证据不充分或有争议

### 3.3 置信度评分

```
1.0  ─ 完全确定：原文明确表述（如"XX是YY的一线治疗药物"）
0.9  ─ 高度可信：原文直接支持
0.8  ─ 比较可信：原文间接支持
0.7  ─ 基本可信：基于常识推理
0.6  ─ 不确定：需要更多上下文
0.5  ─ 猜测：信息不足，标注仅供参考
```

## 4. 边界案例处理

### 4.1 药品联合用药
原文："阿莫西林和克拉霉素联合用于根除幽门螺杆菌"

处理方式：
- 分别标注"阿莫西林"和"克拉霉素"两个药品实体
- 关系从每种药品分别指向"幽门螺杆菌感染"
- 在关系描述中注明"联合用药方案"

### 4.2 否定表述
原文："本品不适用于病毒性感染"

处理方式：
- 不标注"病毒性感染"为适应症
- 标注为禁忌症或使用限制：{"condition": "病毒性感染", "is_contraindication": true}

### 4.3 概率性表述
原文："偶见肝功能异常，罕见严重肝损伤"

处理方式：
- 标注"肝功能异常"和"严重肝损伤"两个不良反应
- frequency 分别标注为"少见"和"罕见"
- confidence 适当降低（因为是统计性描述）

### 4.4 泛指/模糊表述
原文："可能引起消化道反应"

处理方式：
- 标注为不良反应，名称使用"消化道反应"
- confidence = 0.7（因为是泛称非具体症状）
- 在description字段注明原文的模糊表述

## 5. 标注质量评估

### 5.1 评估指标

| 指标 | 计算方式 | 目标值 |
|------|---------|--------|
| 实体Precision | TP / (TP + FP) | > 0.85 |
| 实体Recall | TP / (TP + FN) | > 0.85 |
| 实体F1 | 2*P*R / (P+R) | > 0.85 |
| 关系Precision | TP / (TP + FP) | > 0.80 |
| 关系Recall | TP / (TP + FN) | > 0.80 |
| 标注一致性 | 多标注员一致率 | > 0.85 |

### 5.2 人工抽检流程

1. **抽样**：从每批次标注结果中随机抽取10-20%
2. **审核**：对照原文逐一验证实体和关系的正确性
3. **评分**：计算标注准确率
4. **反馈**：将发现的问题反馈至Prompt优化或标注规范更新
5. **记录**：将质检结果录入quality_checks表
