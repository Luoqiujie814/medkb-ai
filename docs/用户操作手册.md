## 1. 快速入门

### 1.1 环境准备

**系统要求**：
- Python 3.10 或更高版本
- 操作系统：Windows / macOS / Linux
- 磁盘空间：至少 50MB

**安装步骤**：

```bash
# 1. 克隆或下载项目
cd medkb-ai

# 2. 创建虚拟环境（推荐）
python -m venv venv

# 3. 激活虚拟环境
# Windows:
venv\Scripts\activate
# macOS/Linux:
source venv/bin/activate

# 4. 安装依赖
pip install -r requirements.txt
```

### 1.2 5分钟快速体验

无需API Key，使用Mock模式体验完整流水线：

```bash
# 步骤1：采集语料
python src/scraper.py

# 步骤2：清洗数据
python src/cleaner.py

# 步骤3：构建知识库（跳过LLM标注，直接用结构化数据）
python src/kb_builder.py --from-structured

# 步骤4：质量校验
python src/validator.py --db db/medkb.db

# 步骤5：查询知识库
python src/query_engine.py --drug 阿司匹林
```

## 2. 详细功能指南

### 2.1 语料采集

#### 使用内置样本数据
```bash
python src/scraper.py
```
输出示例：
```
📊 采集统计:
   总文档数:     5
   去重后文档:   5
   总字数:       3,247
   数据源:       NMPA药品说明书, PubMed文献摘要, 临床诊疗指南
   输出文件:     data/raw/corpus_sample.json
```

#### 添加自定义语料
编辑 `src/scraper.py` 中的 `SAMPLE_CORPUS` 列表，或创建独立的JSON文件：
```json
[
  {
    "doc_id": "CUSTOM_001",
    "title": "自定义文档标题",
    "source_type": "NMPA药品说明书",
    "content": "药品的完整说明文本..."
  }
]
```
然后指定输入文件：
```bash
python src/scraper.py --input my_corpus.json
```

### 2.2 数据清洗

```bash
# 默认：清洗 data/raw/corpus_sample.json
python src/cleaner.py

# 指定输入输出
python src/cleaner.py --input data/raw/my_corpus.json --output data/cleaned/my_cleaned.json
```

清洗功能包括：
- HTML标签去除
- 全角转半角标点
- 空白字符规范化
- 医药术语标准化
- 中文智能分句
- 质量评分（A/B/C）

### 2.3 LLM信息抽取与标注

#### Mock模式（无需API Key）
```bash
python src/annotator.py
```

#### 使用Claude API
```bash
# 设置API Key（二选一）
export ANTHROPIC_API_KEY="sk-ant-xxx"
# 或直接传参
python src/annotator.py --model claude --api-key "sk-ant-xxx"
```

#### 使用GPT API
```bash
export OPENAI_API_KEY="sk-xxx"
python src/annotator.py --model gpt
```

#### 切换Prompt策略
```bash
# Few-shot策略（快速冷启动）
python src/annotator.py --strategy few_shot

# Chain-of-Thought策略（复杂推理）
python src/annotator.py --strategy cot

# 结构化JSON输出策略（推荐生产使用）
python src/annotator.py --strategy structured_json
```

#### 仅标注前N条文档
```bash
python src/annotator.py --max-docs 2
```

### 2.4 知识库构建

#### 从LLM标注结果构建
```bash
python src/kb_builder.py --input data/annotated/corpus_annotated_mock_structured-json.json
```

#### 从结构化JSON直接构建（跳过标注）
```bash
python src/kb_builder.py --from-structured
```

#### 指定数据库路径
```bash
python src/kb_builder.py --db my_knowledge_base.db
```

### 2.5 质量校验

```bash
# 基础校验
python src/validator.py --db db/medkb.db

# 详细报告模式
python src/validator.py --db db/medkb.db --report

# 保存质检结果到数据库
python src/validator.py --db db/medkb.db --save
```

### 2.6 知识检索

#### 药品查询
```bash
# 详细查询
python src/query_engine.py --drug 阿司匹林

# 模糊搜索
python src/query_engine.py --search 布洛芬
```

输出示例：
```
💊 阿司匹林
   通用名:     Aspirin
   分类:       抗血小板药
   剂型:       片剂
   企业:       拜耳医药

🎯 适应症 (4 项):
   🏅一线 发热 [证据等级: A]
      用法: 口服 0.3-0.6g/次
   🏅一线 冠心病 [证据等级: A]
      用法: 口服 75-100mg/日

⚠️  不良反应 (4 项):
   🟡 胃肠道不适 (常见, 消化系统)
   🔴 消化道出血 (少见, 消化系统)

🔄 药物相互作用 (3 项):
   🔴 华法林: 增加出血风险
```

#### 疾病查询
```bash
python src/query_engine.py --disease 冠心病
```

#### 药物相互作用查询
```bash
python src/query_engine.py --interaction 阿司匹林 华法林
python src/query_engine.py --interaction 奥美拉唑 氯吡格雷
```

#### 全文搜索
```bash
python src/query_engine.py --fulltext 肝毒性
python src/query_engine.py --fulltext 出血
```

#### 知识库统计
```bash
python src/query_engine.py --stats
```

#### 导出结果
```bash
# JSON导出
python src/query_engine.py --drug 阿司匹林 --export aspirin_info.json

# CSV导出
python src/query_engine.py --drug 阿司匹林 --export aspirin_info.csv
```

## 3. 高级用法

### 3.1 完整流水线一键运行

创建运行脚本（run_pipeline.sh）：
```bash
#!/bin/bash
echo "=== Step 1: 语料采集 ==="
python src/scraper.py

echo -e "\n=== Step 2: 数据清洗 ==="
python src/cleaner.py

echo -e "\n=== Step 3: 知识库构建 ==="
python src/kb_builder.py --from-structured

echo -e "\n=== Step 4: 质量校验 ==="
python src/validator.py --db db/medkb.db

echo -e "\n=== Step 5: 知识检索测试 ==="
python src/query_engine.py --stats

echo -e "\n✅ 流水线完成！"
```

### 3.2 自定义Prompt模板

编辑 `prompts/` 目录下的模板文件，添加或修改提示词策略。

### 3.3 批量标注

```bash
# 标注所有清洗后的文档
python src/annotator.py --model claude --strategy structured_json

# 对比不同策略效果
python src/annotator.py --strategy few_shot
python src/annotator.py --strategy cot
python src/annotator.py --strategy structured_json
python tests/test_evaluation.py --compare-all
```

## 4. 常见操作场景

### 场景1：新数据源的导入
1. 准备JSON格式的语料文件
2. 放入 `data/raw/` 目录
3. 运行 `python src/cleaner.py --input data/raw/新文件.json`
4. 运行标注和建库流程

### 场景2：知识库增量更新
1. 准备新增语料
2. 运行采集 → 清洗 → 标注
3. 使用 `--from-structured` 模式重新构建（当前版本全量重建）

### 场景3：质量排查
1. 运行 `python src/validator.py --report` 查看问题
2. 根据报告中的建议逐条修复
3. 重新运行校验确认修复

## 6. 字段参考

### 药品查询返回字段

| 字段 | 类型 | 说明 |
|------|------|------|
| name | string | 药品通用名 |
| generic_name | string | 英文通用名 |
| category | string | 药品分类 |
| indications | array | 适应症列表 |
| adverse_effects | array | 不良反应列表 |
| drug_interactions | array | 药物相互作用列表 |

### 疾病查询返回字段

| 字段 | 类型 | 说明 |
|------|------|------|
| name | string | 疾病标准名 |
| category | string | 疾病分类 |
| drugs | array | 治疗药品列表 |
